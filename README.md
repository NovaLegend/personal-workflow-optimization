# Personal Workflow Optimization

A growing collection of the tools I use to run my day: small, open-source pieces that plan the work, close the loop, and carry context from one day to the next.

Each tool lives in its own folder and can be used on its own.

| Tool | What it does |
| --- | --- |
| [Good Morning!](good-morning/) | Two skills for Claude Code and Codex: a morning plan built from your goals and commitments, and an evening review that compares what happened with what you planned. Plain Markdown, no app to maintain. |

More tools are on the way.

## Principles

- **Plain files over platforms.** Everything is readable in a text editor.
- **Evidence over assumptions.** Records reflect what actually happened, not what was hoped for.
- **Private by default.** The tools hold instructions and fictional examples only; personal records stay in your own workspace.
